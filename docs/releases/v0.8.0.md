# v0.8.0

Signed-in readers can ask questions of the published wiki using OpenAI Codex or
Anthropic Claude Code subscriptions on the shared provider hosted on Velia.

- Ask/Search switch, space filtering, provider and model selection, and cited answers.
- Two bounded model calls select relevant published articles, then answer from
  their full text. Answers identify inference and missing evidence.
- Host-managed native provider logins; no provider or authoring token required
  from readers. No silent provider, model, or billing fallback.
- Isolated execution, disabled agent tools, bounded context and deadlines,
  validated citations, SSO and same-origin checks, and reader/provider admission limits.

Validation included Python and Chromium/WebKit checks, model qualification on
Velia, and full cited answers through both provider adapters. Native provider
login persistence was checked. This is not a claim of a fresh public-browser SSO
test at the time this historical release record was published.

Article synthesis during ingestion and saving answers as wiki articles remain
follow-ups. Ask needs online host subscriptions; reading compiled articles and
ordinary search do not invoke a model.
