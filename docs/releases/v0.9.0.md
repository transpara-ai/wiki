# v0.9.0

Adds continuous discovery, retained research, and human-authorized publication:

- Private SQLite evidence, investigations, findings, durable jobs and recovery.
- Explicitly configured GitHub, page and feed monitors, previewed before enabling.
- Grouped proposals, independent cross-family review, organizational scorecards,
  browser review, and validated publication bound to reviewed revisions.
- Transient Ask follow-ups, explicit saves and feedback, scoped MCP access,
  portable accepted evidence and repository explanations.
- Transpara document-control frontmatter and document SemVer in reviewed article
  diffs. Existing identity, ownership, classification and custom metadata survive;
  curators select major, minor or patch increments. Unversioned history is marked
  unknown. Captured originals remain unchanged.
- The application and MCP server report the same package version.

This is a minor release because it introduces compatible capabilities. Existing
URLs and ingestion/Ask interfaces remain. Install the private worker separately;
configure approved providers and credentials through host-managed files. Monitors
start disabled and no repository is enrolled automatically. Back up private SQLite
state separately from canonical Markdown. Proposals reviewed before document
control was added need fresh review because their frozen content has changed.

The local implementation checks include Python workflows, real isolated
publication, frontend checks and browser workflows. Metadata regression checks
cover preservation, version increments, changed review inputs and release metadata.
See the [implementation validation record](../continuous-discovery/implementation.md).
Live provider qualification, ranking calibration and the human usability pilot
remain deployment acceptance work. Binary documents require supported text
extraction; OCR, transcription, automatic publication and unrestricted crawling
are excluded.

Release publication and deployment are separate maintainer operations.
