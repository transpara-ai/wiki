# v0.11.0

Terminology gains durable browser submissions, review of complete dictionary
bytes and their diff, passkey enrollment requests and Human-approved publication
through a separate private publisher. An ordinary authoring token cannot approve
a dictionary. The publisher verifies a Human passkey bound to the displayed bytes
and a distinct workload signature before advancing its signed runtime ledger.

The scanner accepts one public HTTPS URL or an immutable GitHub repository
capture, with optional ref/path filters and a protected allowlist for private
repository credentials. Bounded jobs report vocabulary deviations,
independent readability findings, provenance and incomplete coverage. Optional
model rewrites retain originals, show diffs, enforce protected text invariants and
rescan the draft. These partial checks never certify ASD-STE100 conformance.

The service is optional and inactive until separately authorized installation,
trust enrollment and activation. Existing snapshot-only deployments retain their
read-only view and draft download. See [the workspace manual](../terminology-workspace.md)
and its linked publication design.
