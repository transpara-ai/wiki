# v0.8.3

The site now links to its GitHub repository with the standard GitHub icon in
the top-right header, beside the theme and profile controls. The link is
keyboard accessible, uses the current theme, and opens in a new tab.

- Stable GitHub Releases are published from the exact main commit after CI
  passes, with checked-in release notes and synchronized SemVer metadata.
- The repository README prominently links to the latest release and history.
- Release validation rejects prerelease versions and mismatched lockfiles;
  publication refuses conflicting tags, drafts, and version regressions.
- Documents the Karpathy pattern audit, including the unfinished ingestion
  synthesis and semantic-maintenance workflows. No claim of full adherence.

Historical v0.8.0, v0.8.1 and v0.8.2 release records are now published with their
original version commits. This patch does not change article content, Ask
inference, authentication, routing, or provider credentials.

Validation: release automation unit tests, existing build/navigation checks,
and Chromium/WebKit header checks. GitHub publication indicates checked source;
deployment and host health are verified separately.
