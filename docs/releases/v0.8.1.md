# v0.8.1

Press Enter in Ask to submit a question. A per-model Effort selector makes the
reasoning setting explicit and remembers the reader's preference.

- Removes the redundant Ask Wiki button and shows an Enter hint.
- Validates effort against the selected model and sends it to both selection
  and answer calls. Responses identify the effort used.
- Uses native Codex reasoning configuration and Claude's effort option.
  Models without an effort control explicitly show that it is unsupported.
- Preserves older API clients that omit effort; no silent effort substitution.

Validation: 20 Ask/backend tests, 13 navigation tests, 34 Chromium/WebKit
checks, and passing CI. Velia canaries and full cited questions confirmed
explicit effort with both providers. Existing configuration, profile data,
and 701 source/article/space files were preserved during deployment.

Implementation: [PR #108](https://github.com/transpara-ai/wiki/pull/108).
Operations: [ASK.md at this release](https://github.com/transpara-ai/wiki/blob/v0.8.1/compile/ASK.md).
