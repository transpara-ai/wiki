# v0.8.2

Makes the shared subscription-provider host boundary reproducible and explicit.

- Adds a root-owned provider configuration and installer.
- Both the provider wrapper and authentication monitor use the configured Unix
  socket through an explicit Docker `--host`, ignoring ambient endpoint overrides.
- Fails closed on missing or writable provider configuration.
- Shadow verification recognizes the exact authentication-proxy runtime paths
  `/oauth2/start` and `/oauth2/sign_out`.

Validation recorded in the merged PR: `npm run verify`, focused provider
configuration and endpoint-override tests, Ask adapter regressions, and a
byte-equivalent authoring/shadow build.

Implementation: [PR #110](https://github.com/transpara-ai/wiki/pull/110).
Migration and provider setup: [ASK.md at this release](https://github.com/transpara-ai/wiki/blob/v0.8.2/compile/ASK.md).

This stable release record was backfilled on September 18, 2026 at the original
merged version commit. Its publication date is not a deployment attestation.
