# RTOI Comparison Framework

This framework compares buying problems, not vendors in the abstract. The interpretations below are **Transpara first-party positioning** based on vendor public material verified on the date above.

| Dimension | Questions to verify |
|---|---|
| Primary outcome | Live operational understanding, data foundation, historian, specialist analytics, or a combination? |
| Data relationship | Live access, replication, selective storage, contextualization, and system-of-record boundaries? |
| Semantic layer | How are assets, KPIs, limits, units, relationships, and governance represented? |
| User workflow | Operator monitoring, management rollup, engineering analysis, app development, or data science? |
| Action path | Alerts, collaboration, workflow integration, write-back, and human approval? |
| Deployment | Vendor cloud, customer cloud, on-premise, restricted network, or full air-gap? |
| Operations | Upgrade ownership, observability, backup/restore, support bundle, and failure isolation? |
| Extensibility | APIs, SDKs, calculations, models, connectors, and governed agent/tool access? |

## Category tendencies, not verdicts

- Transpara publicly emphasizes KPI-centric monitoring, multi-source context, analytics, notifications, and customer-controlled deployment.
- Cognite publicly emphasizes an industrial data foundation, contextualization, knowledge graphs, governance, and application enablement.
- AVEVA publicly emphasizes PI System operations-data infrastructure and PI Vision real-time visualization.
- Seeq publicly emphasizes industrial time-series analytics and publishing analytical insights.

Do not turn these tendencies into scored claims without a named use case, agreed criteria, current evidence, and documented unknowns.
