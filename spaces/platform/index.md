# Transpara Platform Knowledge Base

Current, source-ranked knowledge about the complete Transpara industrial
software platform: its product portfolio, capabilities, architecture,
components, integrations, deployment, security, APIs, and operations.

Visual KPI is one product and capability within this portfolio; it is not a
synonym for the complete platform. Articles distinguish implemented behavior,
normative decisions, planned work, investigation findings, roadmap intent, and
marketing positioning.

Customer production data is not part of this knowledge base. Demonstration
data and customer runtime data remain explicitly different trust domains.
