# September follow-up: Blueprint, Factory/Machinist and Neo

The July evaluation's blanket characterization of Factory as prompt-only
process is now outdated. Its repository presents **Machinist**, with executable
scheduling, durable jobs and GitHub request reconciliation. The pattern-only
adoption decision remains appropriate pending deployment-specific evaluation;
its rationale must now reflect these concrete improvements.

This is the refresh requested by [Wiki #54](https://github.com/transpara-ai/wiki/issues/54),
performed early under the September 9 instruction to resolve all remaining
issues. It is a September observation, not evidence collected in October.
The [July evaluation](tai-res-2026-006-owainlewis-evaluation.md) is preserved
unchanged as a dated source. Its Civilization v4.0 comparison is historical;
the active Civilization deployment now selects external TLC v0.1.2 and has
persisted prepared-result review and Workbench History.

## What changed

**Factory/Machinist.** The current [README](https://github.com/owainlewis/factory/blob/b387fc7/README.md)
describes a control plane and workers invoking locally configured commands.
This is a different implementation from the July runner. The
[scheduler](https://github.com/owainlewis/factory/blob/b387fc7/internal/controlplane/trigger_scheduler.go)
handles interval and cron occurrences, pending occurrence recovery and
configuration generations. GitHub admission checks the requesting actor's
repository permission and reconciles labels after durable admission. Named
[tests](https://github.com/owainlewis/factory/blob/b387fc7/internal/controlplane/trigger_scheduler_test.go)
cover unauthorized actors, label repair without duplicate jobs, stale
configuration and schedule backlog. Tests were inspected, not executed here.

The [SQLite store](https://github.com/owainlewis/factory/blob/b387fc7/internal/controlplane/store.go)
retains job and trigger state. The old repository `JOURNAL.md` append convention
was not found in the inspected current source; durable job/event storage now
provides the relevant continuity mechanism. This finding is not a claim that
every operator-written journal or external integration was searched.

The [Python delivery workflow](https://github.com/owainlewis/factory/blob/b387fc7/agent.py)
checks that the reported open PR closes the requested issue, waits for CI,
compares the current PR head and bounds repair passes. Therefore verification
is no longer adequately described as process exit alone. Some controls still
depend on the invoked agent: the no-merge rule is present in its prompts, and
the launcher grants broad local execution. This review does not establish an
independent prevention mechanism for every command an agent can perform.

**Blueprint.** The pinned [README](https://github.com/owainlewis/blueprint/blob/2aeb882/README.md)
and tracked files contain ten skills: architecture, design, architecture-review,
plan, task-to-pr, codex-issue-coordinator, test, review, improve and html-doc.
The July count of 17 no longer applies. Delivery, evidence and human merge
remain explicit workflow concepts; this is primarily guidance interpreted by
the execution host. Its HTML-document helper is executable tooling, so calling
the entire repository “only markdown” would also be inaccurate.

**Neo.** The current [goal-runner document](https://github.com/owainlewis/neo/blob/ba8543a/docs/design/goal-runner.md)
explicitly labels `/goal` proposed behavior. Source searches did not locate a
goal runner or the former named threshold mechanism in the inspected internal
tree. No completion-threshold enforcement is credited. The
[subagent supervisor](https://github.com/owainlewis/neo/blob/ba8543a/internal/subagent/supervisor.go)
does contain timeout handling. Current sandbox claims require a separate
execution and platform assessment; the July permission-file paths are no
longer a sufficient description of this revision.

## Reception and decision

Fresh September 9 web searches used `"owainlewis/factory" review experience`,
`"owainlewis/blueprint" review`, and `"owainlewis/neo" goal runner`.
Results were mostly maintainer pages and skill directories. A
[Blueprint directory entry](https://claudemarketplaces.com/skills/owainlewis/blueprint/review)
and [another listing](https://www.claudeatlas.com/skills/owainlewis/architecture-review/)
show discoverability, not independent production validation. No substantive
independent adoption or failure study was found in this bounded search. That
is a search limit, not proof that none exists.

Reaffirm **patterns for evaluation, no runtime adoption**. Revisit the old
prompt-versus-code comparison: Machinist now offers concrete examples of
durable admission before label acknowledgment, recovery of pending schedules
and bounded feedback loops. Evaluate those mechanisms against a named
Civilization defect before selecting an integration. No external code was
installed, executed or granted access as part of this research.
